# Shortcuts (Weasis 4.7 docs)

Source: Shortcuts page, version **4.7**. Since **4.7.0** most keys are editable under Preferences > General > Keyboard Shortcuts. Help > Keyboard Shortcuts shows the live map. Defaults below are the Have contract when no user overlay exists.

## Central panel (tabs)

Ctrl+Tab / Ctrl+Shift+Tab cycle tabs. Ctrl+Shift+E docking list. Ctrl+M maximize. Ctrl+W close. Ctrl+E externalize. Ctrl+N normalize.

## 2D DICOM viewer

Series: Left/Right, PageUp/PageDown first/last. Studies: Ctrl+those. Images: Up/Down, Home/End, Shift±10. Patients: Ctrl+Up/Down, Ctrl+Home/End.

Actions: T pan, W window/level, S series, Z zoom, R rotation, H crosshair, C cine, M measure, D distance, A angle, Y polyline, G draw, B textbox, N none, Q context, K key image, P print, Esc reset. Space/I cycle annotation visibility (three states). Alt+S hide/show segmentations (since 4.7.2). 0–9 DICOM presets. F11 / double-click fullscreen (F11 since 4.5.2).

Mouse: left = current action (default W/L), middle = pan, wheel = series. Ctrl / Ctrl+Shift drag accelerate. Alt+arrows pan 5 px; Alt+Shift 10 px.

W/L: horizontal right increases window (less contrast); vertical up lowers center (brighter) unless `weasis.level.inverse`.

Segment draw: click-drag-release **or** click-release-drag-release.

## MPR (since 4.6, plus 2D map)

Alt+X/C/V crosshair center/show on selected view; Ctrl+Alt variants for all views. Ctrl+Alt+B cycles MIP None/Min/Mean/Max. Alt+wheel thickness on selected axis.

## Explorer

Ctrl+click multi-select thumbnails; Shift+click range; Ctrl+A all; Enter open; drag onto view. Selecting a thumbnail raises download priority.

## Graphics

Click select; drag select-area or draw; Ctrl+A/D select/deselect all; Delete remove; Shift+click add/remove or draw on top; double-click ends polyline.
